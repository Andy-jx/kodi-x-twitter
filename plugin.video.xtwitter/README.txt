X（Twitter）Kodi 插件 1.0.1

核心入口
- 首页推荐视频（For You）
- 关注页视频（Following）
- 我的主页视频
- 我喜欢的视频
- 我的书签 / 收藏视频
- 搜索 X 视频
- 打开 X 帖子链接
- 观看历史
- 账号与设置
- 插件诊断

1.0 架构升级
- addon.py 只保留启动职责，路由移到 router.py
- Kodi 21/22 使用 VideoInfoTag；旧 Kodi 自动 fallback
- 播放时优先根据 tweet_id 重新解析当前视频地址，降低临时 CDN URL 过期导致的播放失败
- 推荐/关注/主页/喜欢/收藏/搜索使用 TTL 缓存
- X 接口临时失败时可显示旧缓存
- 登录/退出会清理账号相关缓存
- 自动读取最新 X GraphQL Query ID，仍保留手动覆盖入口
- 诊断页可查看 Kodi、插件版本、Cookie、账号和首页接口状态

登录
1. 浏览器登录 https://x.com
2. 获取 x.com Cookie
3. 最稳：直接复制完整 Cookie；最低要求 auth_token 和 ct0
4. Kodi -> X（Twitter）-> 登录 X -> 粘贴

说明：
- 只有 auth_token + ct0：可验证登录，并使用推荐/关注/书签/搜索等功能。
- 完整 Cookie 如果包含 twid：插件还能自动识别本人账号 ID，用于“我的主页视频/我喜欢的视频”。
- 1.0.1 已停止使用会返回 HTTP 404 的旧 v1.1 verify_credentials 登录接口。

安全
- auth_token 等同登录凭证，不要发送给其他人，不要提交进 GitHub。
- Cookie 只写入 Kodi 插件设置，不写入仓库。
- 退出登录时会清理接口缓存。

说明
X 的非公开 Web GraphQL 接口会变化。插件提供 Query ID 自动更新与手动覆盖，但仍可能需要后续兼容更新。


1.0.4 新增：
- 长按任意视频 → 加入我喜欢 / 移出我喜欢。
- “我喜欢的视频”改为插件本地收藏，不调用 X 账号 Likes，不需要 twid。
